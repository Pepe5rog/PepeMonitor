# PepeMonitor

Настройки всех экранов компьютера в одном окне — без кнопок на самих мониторах.
Работает на любом компьютере с Windows 10/11 и с любыми экранами; что умеет каждый экран, программа определяет сама.

| Экран | Что можно |
|---|---|
| Внешний монитор с DDC/CI | яркость, контраст, резкость, цветовые режимы (sRGB, 6500K…), R/G/B, сброс цвета — меняется внутри монитора |
| Экран ноутбука | яркость подсветки (как клавиши Fn) |
| Любой физический экран, включая ТВ и мониторы без DDC/CI | программно через видеокарту: теплота (2700–6500K), гамма, затемнение |
| Виртуальный экран (PepeDisplay и другие IddCx) | ничего: картинка уходит на устройство раньше коррекции, яркость — на самом устройстве |

Профили (по умолчанию «Дневной» и «Ночной») применяются сразу ко всем экранам: каждому — его сохранённые
значения, иначе общие (`*`). Любой профиль можно вынести ярлыком на рабочий стол.

Питание: «Выключить все экраны» (включаются мышью/клавишей), таймер выключения, настройки Windows «гасить экран» и «сон»;
монитор с DDC/CI, который это умеет, — отдельные «Выкл / Вкл». В режиме «Дублировать» видны все экраны,
но программный цвет у них общий.

Программная коррекция сбрасывается после перезагрузки — галочка «Возвращать при входе в Windows»
кладёт `PepeMonitor.exe --restore` в автозагрузку.

Windows по умолчанию не даёт затемнять программно сильнее ~50%; программа предложит снять ограничение
(`HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\ICM\GdiIcmGammaRange = 256`, нужны права администратора и перевход).

## Запуск

```
python pepe_monitor.py                     # окно
python pepe_monitor.py --profile "Ночной"  # применить профиль без окна (для ярлыков)
python pepe_monitor.py --restore           # вернуть программную коррекцию (автозагрузка)
python pepe_monitor.py --diag [папка]      # отчёт о всех экранах (JSON + TXT), --no-gamma — без теста gamma
```

Коды выхода: 0 — готово, 1 — экраны не найдены, 2 — нет такого профиля.
Настройки и профили: `%APPDATA%\PepeMonitor\settings.json`.

## Сборка

Нужны Python 3 с `pyinstaller` и `pillow`, Inno Setup 6.

```
build.cmd
```

Результат: `dist\PepeMonitor.exe` и установщик `installer_output\PepeMonitorSetup-<версия>.exe`
(ярлыки в меню «Пуск»: программа, «Дневной режим», «Ночной режим»; по желанию — на рабочем столе).

## Устройство

- `displays.py` — перечисление экранов (EnumDisplayMonitors + EDID из реестра + WMI: тип подключения, подсветка), gamma ramp;
- `ddc.py` — DDC/CI через `dxva2` (строка возможностей монитора, чтение/запись VCP);
- `power.py` — выключение экранов, таймауты электропитания (powercfg);
- `diag.py` — отчёт `--diag`;
- `pepe_monitor.py` — окно (tkinter), профили, режим командной строки.

Многие мониторы (например, на скейлерах Realtek) принимают смену цветового режима, но при чтении
возвращают неверное значение, поэтому подсвечивается режим, который последним включили из программы.
